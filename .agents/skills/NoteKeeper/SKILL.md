# NoteKeeper

## 任務目標

將用戶臨時輸入的文字、連結或碎片化資訊自動化「規格化」並「存檔」至 `_data/note.md` 中。確保內容易於閱讀、按周分類，且新筆記始終在最上方，方便快速回顧。

## 執行指南

### [Input]
- 用户隨手記錄的文字
- 網址連結 (URL)
- 圖片附件（若有的話，需生成描述）
- 檔案內容片段

### [Process]
1. **內容過濾與格式化**：
   - **字數與摘要決策**：
     - 若原始內容字數**大於或等於半頁 A4**（約 400 - 500 個中文字）：
       - 必須撰寫**完整且深度的摘要**，字數應**至少達到半頁 A4 的規模（400 - 500 字以上）**。
       - 摘要內容應包含：核心觀點、關鍵案例與實證、產業定位/情境分析，以及啟示或結論。
     - 若原始內容字數**低於半頁 A4**（少於 400 個中文字）：
       - **不進行任何摘要簡化**，必須**完整保留**原始來源的內容。
       - 對保留下來的完整內容進行**精心排版**，使用適當的 Markdown 語法（標題、清單、粗體、代碼區塊、引言區塊等）進行結構化整理，確保可讀性。
   - **網址處理**：
     - 若為網址，除了抓取網頁 `<title>` 並標記為 `[Link]` 型態外，必須抓取網頁的主要文字內容，再依上述字數決策進行深度摘要或完整排版。
   - **代碼片段**：若為代碼片段，使用相應的 Markdown 代碼塊包裝。
2. **日期定位**：
   - 獲取當前台灣時間與周數 (Week Number, ISO 8601)。
   - 生成標題格式：`### YYYY-MM-DD (Day) HH:MM`。
3. **分段管理**：
   - 檢查 `_data/note.md` 中是否已存在該周的區塊標題（格式：`## YYYY-Wxx (YYYY/MM/DD - YYYY/MM/DD)`）。
   - 若不存在，則在 `_data/note.md` 最上方插入該周標題（緊接在 Markdown 文件的主標頭之後）。
4. **插入內容 (Prepend)**：
   - 將格式化後的筆記內容插入到對應周標題的正下方。

### [Output]
- 更新後的 `_data/note.md` 檔案。

## 注意事項與準則

- **Prepend 優先**：確保新周標題在最上方，新筆記在對應周標題下方。
- **摘要完整度**：長文的摘要絕對不可草率。務必確保有足夠的細節與脈絡，字數須滿半頁 A4。
- **原文保留**：對於短篇實用資訊、短代碼、簡短引文等，直接保留並排版，絕不強行縮寫。
- **連結處理**：務必檢查網址有效性，並嘗試擷取有意義的頁面標題。
- **排版風格**：保持簡約、高對比，並使用適當的 Emoji（💡, 📖, 📝, 📅）增加可讀性。
