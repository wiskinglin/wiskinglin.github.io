MODULE 1

邊緣運算與分佈式存儲架構哲學

設計理念與全球邊緣覆蓋
「從一開始就分片 (Start Sharded)」

現代網路應用不再建議依賴集中式的單一龐大資料庫。相反地，應該將資料與運算邏輯徹底解耦，分散至全球數百個邊緣節點的無數個小型儲存基元中。例如，為每個 SaaS 租戶部署一個獨立資料庫或狀態協調物件。

全球覆蓋與零流出成本
  • 275+ 全球邊緣節點覆蓋，讓運算與資料離使用者更近。
  • Zero 完全免除 R2 資料流出 (Egress) 費，解放資料重力。

D1 邊緣 SQL 資料庫 與 Workers KV

SQLite 事務與全域鍵值優化
D1 邊緣 SQL SQLite 全托管庫

D1 基於 SQLite 構建，透過前端 Worker 代理 single-thread 實例以保證絕對事務一致性。其計費採用極具顛覆性的「按讀寫列計費」模型。

計費指標 免費方案 (每日) 付費方案 (每月)
資料列讀取 5,000,000 列 首 250 億列免費 ($0.001/M)
資料列寫入 100,000 列 首 5000 萬列免費 ($1.00/M)
總儲存空間 最大 5 GB 5 GB 免費 (超額 $0.75/GB)
全域讀取副本 (Read Replication)：D1 原生內置主從副本同步。為防止副本延遲，應使用 Sessions API 建立書籤（withSession(bookmark)），確保順序一致性與單調讀取。
Workers KV 全球讀取優化庫

KV 犧牲了寫入傳播的強一致性，以背景非同步廣播換取 Sub-10ms 全網讀取延遲。然而其寫入計費成本為讀取成本的 10 倍。

最佳實踐場景
A/B測試旗標、語系翻譯字典、微服務靜態路由配置。
絕對反模式

MODULE 4

Durable Objects (DO)

強一致性的單執行緒邊緣協調中樞
Durable Object 生命週期與狀態
  • 1. 活躍駐留：Active, in-memory，計費運算時長。
  • 2. 閒置不休眠：Idle, non-hib，有活動計時器。
  • 3. 閒置可休眠：Idle, hib，符合休眠四條件。
  • 4. 休眠中：Hibernated，完全免時長費。
  • 5. 已停用：Inactive，清空記憶體。
DO 運算與 SQLite 持久化計費
  • 運算請求：免費方案 10 萬/日，付費 100 萬/月 ($0.15/M)
  • 執行時長：免費 13,000 GB-s/日，付費 400,000 GB-s/月
  • WebSocket 優待：20:1 合併請求計費，支援 Hibernation
  • SQLite 存儲：免費 5GB 總額，付費單物件上限 10GB
⚠️ 隔離性陷阱： 透過 sql.exec() 取得的游標不保證跨非同步邊界 (await) 的快照隔離。務必使用 .toArray() 在單一同步區塊內徹底消耗結果集。
混合存儲架構最佳實踐 (The Hybrid Pattern)

不要將 Durable Objects 當作唯一的歷史交易資料墳場。正確的微服務拓撲應該是：

1. 當下權威即時狀態

寫入強一致性的 DO SQLite (單執行緒處理無 Race)

2. 異步排程推送

利用 DO 內建的 Alarms 觸發定時器，分批提取歷史穩態資料

3. D1 資料庫持久化歸檔

非同步推送到外圍 D1，用於歷史多維度報表與關聯分析

MODULE 5

Hyperdrive 與 AI 檢索生態系

橋接傳統資料庫與次世代知識庫
Hyperdrive 橋接傳統資料庫

為了解決無伺服器架構瞬間啟動成千上萬 Worker 導致後端地端/雲端 DB 「TCP 連線耗盡 (TCP Connection Exhaustion)」 的問題，Hyperdrive 建立並長期維護全局連線池與邊緣快取機制。

  • 免費方案配額： 每日 100,000 次操作。
  • 並行連線數限制： 免費層 20 / 付費層 100。
  • 加密： 支援端到端 TLS 憑證與 mTLS 加密。
Vectorize 與 AI Search 生態系統
Vectorize 向量維度計費

免費層提供 30M查詢/5M存儲維度；付費層 50M查詢維度 ($0.01/M)。單向量上限 1536維 (float32)。

AI Search & R2 數據源整合

自動排程讀取 R2 Bucket 作為攝取源，內建持久化存儲與 Web 爬蟲。免費索引容量：100實例/10萬個檔案，單檔案最大 4 MB。

💡 R2 資料攝取技巧：可透過 include 與 exclude 路徑過濾規則精準控制索引範圍，並能動態提取 R2 自訂標頭注入中繼資料中。
MODULE 6

基礎運算、任務與全域合成指南

Wall-clock 限制與架構合成指南
Workers CPU 限制與 Wall-clock time

免費方案單次請求享 10ms 限制；付費版 CPU 上限可放寬至 5 分鐘。

重要觀念：CPU 時間僅計算 V8 引擎實際運算週期；所有的 await fetch()、D1 資料庫回源或 R2 讀寫產生的等待期，均不計入 CPU 消耗。超過 CPU 限制將擲回 1102 Worker exceeded resource limits 錯誤。

Queues 佇列與 Workflows 狀態機

Queues 已正式下放至免費版（最大1萬個佇列，每日1萬次操作）。Payload 以 64 KB 作為計費區塊單位。Workflows 全面整合於現有 Workers 計費架構（僅需付 $0.20/GB-月 狀態儲存費）。

Workers AI 神經元經濟學

每日提供所有用戶 10,000 個免費神經元（Neurons）。耗盡後付費層按 $0.011/K神經元 計費，免費層直接阻斷並回傳 3036 異常。AI Gateway 整合 DLP 防止機密外洩。

Cloudflare 最佳化架構合成指南 (Synthesis)
① 責任與實體完全分離 (Object-per-entity)

一律將圖片/文檔歸入 R2 (免除 Egress 費)；D1 與 KV 僅記錄 URL 與 Meta 中繼資料。

② 動靜分離與快取分層 (Dynamic-Static Split)

靜態資源丟 Pages 託管；極少變更路由、翻譯塞 KV；複雜關聯資料歸 D1 持久化。

③ 強一致性混合存儲 (The Hybrid DO-D1 Pattern)

並發更新使用單執行緒 Durable Objects 作為「即時真相來源」，再用 DO Alarms 定期背景同步穩態資料至 D1 作為「歷史分析來源」。

④ 免費額度網異步解耦 (Decouple with Queues)

利用 Queues 與 Workflows 進行異步非同步解耦與突發流量削峰，新創團隊甚至能實現 100% 零基礎設施成本的全球架構。
