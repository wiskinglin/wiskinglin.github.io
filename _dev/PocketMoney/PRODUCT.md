## 1. 一句話定位與核心承諾

- **產品定位**：**個人現金流與扣款安全管理工具（Personal Cash Flow Control Dashboard）**。
- **核心策略**：**Cash Flow First（現金流與流動性防禦優先）**——不以記下每一筆日常消費為目標，而是以「已知銀行餘額、信用卡帳單、分期付款、固定費用與預期收入」，精準判斷**未來扣款是否安全**，以及**扣款後還有多少現金可以安心動用**。
- **產品核心承諾**：
  > 「不用每天記流水帳，每月只要花 3 分鐘更新銀行餘額與卡費，就能知道未來帳單何時扣、哪個銀行帳戶會不足，以及扣款後還有多少錢可以安心安排。」

## 2. 為什麼不做傳統流水帳？（市場差異化）

| 維度 | 傳統流水帳 App（如 CWMoney / 記帳城市） | 全資產看板（如 FINXI / Monarch） | **PocketMoney（水位與扣款防禦）** |
| :--- | :--- | :--- | :--- |
| **記錄粒度** | 每筆便當、飲料逐筆輸入 | 聚焦總淨值與投資報酬率 | **抓大放小**：只管帳戶餘額、帳單總額、固定扣款與 `>$5,000` 大額消費 |
| **核心解答問題** | 「上個月外食花了多少錢？」 | 「我現在總身家有多少？」 | **「月底 20~30 號哪個銀行戶頭不夠扣款？扣完還剩多少錢能花？」** |
| **最大失敗風險** | 3~7 天因輸入疲勞而放棄 | 帳面淨值很高，但指定扣款戶頭餘額不足導致違約跳票 | 若無跨月沉澱與未來推估，容易淪為單月一次性計算機 |
| **核心差異化** | 事後分類統計 | 跨資產淨值彙總 | **「指定扣款銀行帳戶層級」的壓力測試與未來現金流滾算** |

## 3. 目標客群與三大代表人物（Personas）

### 3.1 五大痛點客群
1. **多銀行／多信用卡使用者**：存款分散在薪轉戶、高利活存戶、交割戶，不清楚哪個帳戶在幾號前要預留多少扣款資金。
2. **有分期付款／固定貸款者**：單筆零利率分期看似無痛，但多筆疊加後悄悄吃空每月自由現金流。
3. **排斥逐筆記帳者**：曾嘗試記流水帳但半途而廢，需要極低摩擦（每月 1~2 次盤點）的財務掌控感。
4. **夾心家庭財務管理者**：同時背負房貸、托育、雙月水電瓦斯與家庭卡費，不容許任何一筆自動扣繳失敗。
5. **波段／存股投資者**：需要清楚區分「日常扣款保命錢」與「證券交割戶待命現金池」，避免買股買到月底卡費跳票，或放太多閒置資金（Cash Drag）。

## 4. 每月真實金融時序（產品節奏基線）

系統所有功能皆圍繞台灣使用者每月的真實金融事件運轉：

| 每月時序 | 金融事件 | 使用者在 PocketMoney 的核心動作 |
| :--- | :--- | :--- |
| **5 號** | 薪資入帳 | 一鍵確認薪資入帳（或由系統自動滾算推估），建立當月現金起點 |
| **5 ～ 10 號** | 信用卡出帳 | 收齊各家帳單，快速輸入本期帳單總額，並補記 `>$5,000` 大額消費原因 |
| **10 號** | 房租扣款 | 檢視首波固定費用（房租）由指定銀行直接扣款 |
| **10 ～ 19 號** | **盤點與跨行調度（黃金防禦期）** | 檢視「戶頭扣款安全檢查」紅綠燈；若有紅燈缺口，提早由富餘帳戶跨行轉帳補足 |
| **20 ～ 30 號** | 信用卡與水電代繳、車貸/房貸扣款 | 20~30 號各卡自動扣繳、28 號房貸車貸扣款；月底一鍵結算或進入次月滾算 |
| **不定期** | 股票除息／波段買賣平倉 | 登記股利入帳或賣出平倉交割款，自動聯動證券交割銀行餘額與持股水位 |

## 5. 核心成功指標（Success Metrics）

1. **首次價值時間（TTV, Time-to-Value）**：新使用者從開啟網頁到看懂自身「月底扣款安全紅綠燈與可支配結餘」的時間 **$\le 3$ 分鐘**。
2. **月度維護時間**：老手每月更新銀行餘額與信用卡帳單的操作時間 **$\le 3$ 分鐘（點擊次數 $\le 10$ 次）**。
3. **扣款風險零漏報**：單一銀行帳戶餘額不足以支付綁定卡費＋直扣固定費用時，100% 觸發紅燈與差額預警（絕不因全部銀行總資產大於總負債而誤判安全）。
4. **數據可追溯性**：首頁每一項統計指標（總淨資產、待扣總額、預估結餘、常態固定成本）皆有明確公式，且不重複計算（例如：刷卡代繳水電費不重複扣減銀行餘額）。

## 6. 產品護欄：我們「刻意不做」的事（Anti-Goals）

在 `SCENARIOS.md` 評分時，凡觸犯以下原則的需求，**定位契合度一律計為 `0`（直接淘汰）**：
1. ❌ **不做每日瑣碎流水帳**：不提供餐飲、交通、娛樂等日常小額逐筆分類記帳。
2. ❌ **不依賴高風險銀行帳密爬蟲**：堅持 Local-First 100% 本機隱私，不要求使用者輸入網銀帳號密碼。
3. ❌ **不做無數據依據的 AI 投資報明牌**：只做基於使用者真實部位的水位風控與損益試算，不預測股價漲跌。
4. ❌ **不在畫面上堆砌工程術語與版本號**：嚴格遵守 `specs/UXD.md` 第零章「零 AI Slop 鐵律」。
