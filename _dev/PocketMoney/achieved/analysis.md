# PocketMoney 與市面財務管理 App 比較

## 這個 app 的定位

PocketMoney 不是一般記帳 app，而是**以台灣上班族「30 號扣款檢核」為核心的現金流與資產儀表板**。主要功能如下：

- 確認各銀行帳戶的餘額，夠不夠付當月信用卡費與水電房租
- 信用卡分期的負債與每月現金流壓力
- 台股持股與現金比例（目標 70%，現金上限 30%）
- 只記 $5,000 以上的大額消費（「抓大放小」）
- 資料全存在瀏覽器本地，有 PIN 碼鎖定，可匯出 CSV 與備份

## 市面上的主流 app

| App | 主要特色 |
|---|---|
| **CWMoney 理財筆記** | 下載數超過 500 萬次，被視為台灣最受歡迎的記帳 App，更像「資產管理 App」；可掃描發票 QR Code 自動帶入消費記錄並對獎，也支援多幣別 |
| **MoneyBook 麻布記帳** | 能與各大銀行帳戶同步，涵蓋信用卡、證券戶與電子票證，並有待繳費用提醒；但需要提供網銀帳密，安全性是主要疑慮 |
| **Ahorro** | 介面簡潔，可自訂分類，並支援自動掃描發票，適合初學者 |
| **Moze、AndroMoney 等** | 介面美觀、圖表豐富、上手快 |

## PocketMoney 的優點

1. **直接解決「月底夠不夠扣款」的痛點**：這是一般記帳 app 較少處理的情境。它會把未繳卡費與水電房租歸戶到指定銀行，直接顯示扣款後剩餘金額。
2. **信用卡分期管理清楚**：「每月被分期吃掉的現金流」與「分期未繳負債」兩個指標，一般記帳 app 很少這樣整理。
3. **符合台灣習慣**：有 10 號收單、20 號扣款的邏輯、紅漲綠跌的台股慣例，以及雙月、季繳費用的折算。
4. **隱私性高**：資料不上雲、不需要綁定帳密，也不用註冊，對比 MoneyBook 的帳密問題是明顯優勢。
5. **記帳門檻低**：只記大額與帳單總額，不必逐筆輸入，較容易長期維持。
6. **免費、可離線、可匯出 Excel**：沒有訂閱費，資料沒有被平台綁住。
7. **內建示範情境**：小資族、家庭、高資產三種模型，方便試用。

## PocketMoney 的缺點

1. **所有資料要手動輸入**：沒有銀行同步，也沒有發票載具串接，餘額與帳單都要自己更新，長期下來容易忘記而失準。
2. **缺少日常記帳功能**：沒有逐筆流水帳、分類統計、預算設定，看不出「錢花去哪」，只能看到「現金夠不夠」。
3. **資料只存在瀏覽器**：換手機、清除瀏覽器資料就可能遺失，必須自己定期匯出備份。這是最大的風險。
4. **PIN 碼保護有限**：這是前端的本地鎖，防君子不防小人，不等同加密。
5. **沒有雲端同步與多人共用**：手機與電腦之間要手動匯入匯出，不適合夫妻共同管理。
6. **投資功能偏單一**：只支援台股，且市價要手動輸入，沒有即時報價、配息紀錄、美股或基金。外幣帳戶也沒有明確支援。
7. **沒有推播提醒**：網頁無法在扣款日前主動通知，不像 MoneyBook 有待繳提醒。
8. **非原生 app**：沒有 widget、生物辨識，使用體驗與穩定性不如商店上架的 app。

## 該怎麼選？

- **懶人、想自動化**：選 MoneyBook，但要接受提供網銀帳密的風險。
- **要完整日常記帳與發票對獎**：選 CWMoney 或 Ahorro。
- **在意隱私、有信用卡分期或多家銀行扣款，想掌握月底現金流**：PocketMoney 很適合，它補的正是其他 app 弱的地方。
- **最佳組合**：用 CWMoney 這類 app 記日常花費，再用 PocketMoney 做每月 30 號的檢核，兩者互補，而不是互相取代。

## 改善建議

如果這是你自己開發的工具，最值得優先補的是：

1. 提醒備份的機制，或自動匯出
2. 轉成 PWA，可以安裝到手機主畫面並離線使用
3. 台股報價自動更新
4. 扣款日前的通知
5. 加密本地資料，而不只是 PIN 鎖畫面
