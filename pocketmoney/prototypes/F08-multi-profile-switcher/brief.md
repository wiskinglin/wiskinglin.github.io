## 1. 核心問題與心智模型轉型

### 痛點背景
1. **新手體驗門檻高（冷啟動難題）**：
   - 初次造訪使用者面對完全空白的畫面，不知道從何開始輸入，無法一眼看出 12 個月現金流圖表、Safe-to-Spend、T+2 交割安全水位與分期退坡等核心圖表的威力。
2. **一人多角色的財務孤島**：
   - 現實中單一使用者往往身兼多重角色：個人生活帳（薪轉與日常開銷）、家庭公用帳（夫妻共有公費、房貸水電）、副業工作室帳（外包專案款、設備採購與軟體授權）。傳統軟體需頻繁登入登出或混雜於同一帳本，造成記帳混亂。

### 財務心智模型重塑：雙軌架構 (Dual-Track Architecture)
系統在頂部常駐導覽列整合「Profile 雙軌切換器」，並建立沙盒保護屏障：
- **軌道 A（使用者自建帳本）**：免登入/登出，0.1 秒秒級切換各帳本，各帳本的銀行、信用卡、固定費用、分期與收支規則完全獨立隔離。
- **軌道 B（教學示範帳本）**：預載三大真實生活情境，任何操作與計算僅存於獨立沙盒空間，絕不污染使用者個人自建帳本，並隨時支援一鍵重置。

## 3. 教學示範沙盒保護機制 (Sandbox Protection)

```
┌────────────────────────────────────────────────────────────────┐
│                      Profile 儲存空間隔離                      │
├──────────────────────────────┬─────────────────────────────────┤
│  使用者自建空間 (真實資料)   │   示範沙盒空間 (完全隔離保護)   │
├──────────────────────────────┼─────────────────────────────────┤
│ • PocketMoney_exp_F08_       │ • PocketMoney_exp_F08_          │
│   profile_prof_personal      │   profile_demo_junior           │
│ • PocketMoney_exp_F08_       │ • PocketMoney_exp_F08_          │
│   profile_prof_family        │   profile_demo_sandwich         │
│ • PocketMoney_exp_F08_       │ • PocketMoney_exp_F08_          │
│   profile_prof_studio        │   profile_demo_stock            │
└──────────────────────────────┴─────────────────────────────────┘
          ▲                                    ▲
          │                                    │
  [常規真實帳本操作]                  [隨意試算、修改、刪增]
                                               │
                                       [一鍵重置示範資料]
                                               ▼
                                      還原為初始 Pristine JSON
```

1. **視覺識別與沙盒橫幅**：
   - 切換至示範帳本時，頂部 Switcher 自動標註 `示範` 膠囊徽章。
   - 頁面頂端立即展開琥珀色「示範沙盒」保護橫幅，清楚提示：`修改僅存於沙盒，不影響真實帳本`。
2. **防交叉污染（No Cross-Contamination）**：
   - 示範帳本的任何編輯（如修改餘額、新增交易、刪除分期）嚴格限制在 `PocketMoney_exp_F08_profile_demo_*` 鍵值內。
   - 切換回任何自建帳本時，真實數據 100% 保持純淨原樣。
3. **一鍵精準重置 (Pristine Restore)**：
   - 沙盒橫幅與管理彈窗均提供「重置示範資料」按鈕。
   - 點擊後立即以內嵌之三大場景標準 JSON 覆寫該沙盒，0.1 秒內無損還原。
