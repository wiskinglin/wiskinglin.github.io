## [v0.3.0] — 2026-11-05（F15 八大分頁唯讀洞察重構 ＋ 雙階段每月盤點 ＋ F08 多帳本切換 ＋ 手機版 RWD 整合）

### 新增與整合 (Added & Integrated)
- **F15 總覽與八大分頁唯讀洞察重構 [INTEGRATED]**：
  - 八大分頁（總覽、銀行、卡片、固定費用、台股部位、分期付款、收支規則、系統設定）100% 唯讀資料洞察視圖，全面移除各分頁原地破壞性修改按鈕。
  - 落實 ADR-016 三段式時間模型：過去月份封存存量回溯、當月即時日進度扣款防禦水位、未來月份流量預估。
  - 嚴格遵守零 AI Slop 介面鐵律，移除所有內部架構術語、版本標籤與教學式說明副標題。
- **雙階段每月盤點輸入流 (Monthly Inventory Drawer)**：
  - 右上角常駐「+ 每月盤點輸入」抽屜：
    - **階段一**：更新活存與備用金餘額、登記各卡新帳單與大額消費。
    - **階段二**：指定各卡繳款銀行，即時預覽扣款後的銀行餘額與防禦警示。
- **F08 多帳本切換器 (Multi-Profile Switcher) [INTEGRATED]**：
  - 支援「個人生活帳」、「家庭公用帳」、「副業/工作室帳」無縫秒級切換。
  - 示範資料沙盒一鍵重設與載入，測試不污染正式資料。
  - 完全相容 `STORAGE_KEY = 'PocketMoney_tw_finance_v3'` 與 `PROFILES_META_KEY = 'PocketMoney_profiles_meta_v1'`，使用者本地儲存資料無縫延續。
- **全站手機版 RWD 全面優化**：
  - 響應式頂部導覽列、抽屜選單與彈性排版。
  - 消除 375px~390px 寬度下的所有水平捲軸與破版，通過 Playwright 0-error 驗收。

## [v0.2.0] — 2026-11-03

### 新增 (Added)
- **盤點基準日架構 (Snapshot Date)**：新增 `settings.snapshotDate`，舊資料載入時支援自動備份並設定盤點基準日（預設 2026-10-31），確保歷史資料不重複扣款。
- **信用卡逐月 Records 與金額動態化**：信用卡支援逐月 `records[{year, month, amount, bigExpenses, status}]` 陣列，卡片總額、大額消費與未繳負債隨頂部日期控制列動態響應。
- **日期自動判定扣款與異常例外處理 (ADR-001 方案 B 落地)**：盤點基準日之後的帳單於扣款日自動判定扣款入帳，若銀行餘額不足或異常可標記為「扣款失敗」或手動重試。
- **專案編號總表 (Feature Registry) 與多輪原型架構**：在 `BACKLOG.md` 建立發號登記總表，原型目錄結構統一納入 `r1/`、`r2/` 實驗輪次，路線圖待辦重整為 `F07`（漸進式解鎖）與 `F08`（Profile 切換）。

### 變更 (Changed)
- **登記本期帳單抽屜**：由全域修改 `statementTotal` 改為直接寫入當前檢視年月份的 `records`，若在盤點月登記則雙向同步相容舊欄位。

## [v0.1.0] — 2026-11-03（F04 多帳戶多信用卡版面 ＋ F05 日期控制導入 ＋ F06 對帳單分析器）
### Added（新增與整合）
- **F09 初次使用與重設資料全面歸零 [ADR-015]**：
  - 徹底移除 DEFAULT_STATE 中的預設寫死示範數據（台新、中信、永豐、CUBE卡等），所有帳戶、信用卡、收支規則、分期與持股預設皆清空歸零（空陣列）。
  - 修復設定頁「完全清空重設」按鈕，執行時確實執行 localStorage.removeItem 清除本地儲存並重設狀態重新渲染，達成真正零狀態。
- **取消 F03 扣款缺口跨行調撥與單期覆寫 [ADR-014]**：
  - 經使用者評估判定該功能無實用效益，正式從待辦清單中廢棄不實施。
- **F06 外部對帳單與明細分析器 (`pocketmoney/analyzer`) [ADR-013]**：
  - **獨立雙欄比對檢驗器 (`viewer.html`) [F06-Viewer]**：提供獨立單檔 HTML 工具，支援左欄 PDF 憑證即時預覽、右欄四大標準化資料模組（帳單摘要與自動平帳檢核、約定扣繳檢核卡、長週期分期付款進度條、消費明細標準表格）。支援載入 `pocketmoney_db.json` 與拖曳檔案對照。
  - **模組架構與機敏隔離**：獨立建立 `analyzer/` 程式套件（納入 Git 版本控制），並於 `.gitignore` 嚴格隔離真實 `samples/`、所有 `*.pdf` 與個人 `result/*.json`。
  - **三大銀行信用卡帳單剖析器**：支援國泰世華、台北富邦、玉山銀行原生數位 PDF 之應繳總額、扣款日、扣繳帳號、卡號末四碼與消費明細。
  - **長週期分期付款自動追蹤**：精準解析 `20/24`、`分30期之第15期`，並自動倒推回起算年月 (`startYear/startMonth`) 與剩餘金額。
  - **通用 DB 累積合併引擎 (`merge_engine.py`)**：每次執行增量將最新帳單數據合併寫入 `result/pocketmoney_db.json`，格式嚴格相容主程式 `pocketmoney.html` 之 `importDatabaseJSON`，可直接於設定頁「匯入 JSON 資料庫」一鍵載入。
  - **未來擴充介面**：保留 `securities/`（證券持股與除權息）與 `banks/`（存摺收支明細）擴充介面。
- **F04 方案 B 自適應版面**（帳戶或信用卡 ≥ 4 才啟用，少於 4 維持原平鋪）：
  - 首頁扣款安全檢核改為例外優先：不足帳戶置頂並附調撥建議（含「調撥」確認動作），其餘充足帳戶收斂為摘要列，可展開檢視。
  - 銀行餘額分頁新增「卡片網格 / 緊湊表格」切換（預設緊湊表格）。
  - 信用卡費分頁：本期無消費的卡片收納為可展開摘要列；新增「依卡片顯示 / 依扣款銀行歸戶」切換。
  - 趨勢圖預設只畫銀行總餘額與餘額前 3 名帳戶，點選帳戶標籤可單獨聚焦。
- **F05 日期控制**：頂部新增「前月 / 指定日期 / 次月 / 回到今天」列；檢視日期只存在本次瀏覽，不寫入儲存資料。扣款倒數、收入生效月份、收支時序軸、趨勢圖當月皆依檢視日期計算。
- **F05 帳單登記抽屜**：信用卡費瀏覽狀態金額改為純文字，新增「登記本期帳單」抽屜（電腦為右側滑出、手機為底部面板）批次填寫各卡帳單。
- **分期自動推進**：分期設定新增選填「起算年月」；填寫後期數依檢視月份自動推算，不再提供手動「+1 期」。

### Changed（調整與改進）
- `APP_VERSION` 升為 `0.1.0`（`STORAGE_KEY` 不變，資料向下相容；分期新增 `startYear / startMonth` 為選填欄位）。
- 信用卡卡片的「本期帳單總額」由行內輸入改為文字顯示，修改請用「登記帳單」。

### 未納入（F05 原型內容）
- 原型的「時序測試」快捷按鈕與頁面頂部狀態條屬測試輔助，未帶入。
- 原型的信用卡逐月 `records`、依日期自動判定已扣款、銀行餘額模擬扣款，與 Main 現行「手動確認扣款」模型衝突（見 ADR-001 方案 A），暫不導入，信用卡金額不隨檢視月份切換。

## [v0.0.1 / v3.6-dev] — 2026-11-03（F01 定案合併：Input 參數與收支規則中心）
### 交付與合併（採方案 B，ADR-009）
- **收支規則設定分頁（`tab-rules`）**：集中管理「每月薪資＋其他收入（`inflows`）」、「各信用卡結帳日與扣款日」、「固定費用扣款日與扣款管道（銀行直扣 vs 信用卡代繳）」，支援規則總表行內即時修改。
- **信用卡自訂結帳與扣款日**：拔除寫死之「30號扣款 / 10號收單」，支援每張信用卡各自設定 `closingDay` 與 `dueDay`。
- **信用卡帳單三段拆解**：清楚拆解 `分期攤提 + >$5,000 大額 + 一般日常消費`。
- **固定費用扣款防重複機制**：支援設定 `每月幾號扣款`，並區分 `銀行帳戶直扣` vs `信用卡代繳（card_auto）`，代繳帳單自動納入信用卡帳單預估，不於銀行端重複扣款。
- **首頁「1～31 號收支時序預覽條」**：直觀視覺化當月各日期的進帳與扣款時序，明確呈現發薪日與扣款日的先後時差。
- **未來現金流推估連動**：依各收入生效月與分期剩餘期數，自動計算隨分期到期而減少之月支出負擔。

## [v3.0] — 2026-10-29（`tools/kipomo.html` 正式版基線）
### 核心功能
- 三階段新手導覽（Welcome Modal + 原生 0 依賴 SVG Spotlight + 首頁 4 項動態任務檢查清單）。
- 總淨資產、股票投資損益、本月待扣款總結三大頂部 KPI 卡。
- 每月 30 號各銀行自動扣繳安全檢查（紅綠燈預警、單一銀行扣款、全數一鍵扣款、新月份重置）。
- 信用卡 `>$5,000` 大額消費雷達、進行中分期付款追蹤、固定費用三大 KPI 與雙月平準化。
- 4 位數本地 PIN 碼鎖定、金額隱私遮罩、UTF-8 BOM Excel CSV 匯出、JSON 備份還原與單機自封裝 HTML 下載。
