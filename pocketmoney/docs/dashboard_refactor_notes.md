# 總覽頁面功能重構討論筆記 (Dashboard Refactor Notes)
- 記錄時間：2026-11-04
- 討論核心：總覽頁面資訊重整與單月現金流趨勢圖設計

### 1. 遺漏項目補齊盤點（總覽頁現存之其他區塊）
除了頂部 3 大 KPI 卡與趨勢圖外，目前總覽頁下方實際還包含：
1. **1~31 號時序長條軸 (`dashboardTimelineContainer` / `cashflowTimelineCard`)**：顯示當月每天發生的扣款/流入小圓點與游標。
2. **扣款安全檢核清單 (`bankCheckupGrid` / `autoDebitAuditCard`)**：各銀行的不足警示與充足收折。
3. **本月大額消費列表 (`dashboardBigExpensesList`)**：卡片中超過 $5,000 的單筆消費清單。
4. **進行中分期付款摘要 (`dashboardInstallmentSummary` / `installmentModule`)**：分期期數、每月扣繳與進度條。

### 2. 本月已知的現金流出項目盤點 (Known Cash Outflows)
每個月已知的現金流出分為三大確定來源：
- **A. 固定支出 (Bills - 銀行直扣)**：如房租、管理費、貸款本息等（每月固定日期直接由銀行扣除）。
- **B. 信用卡代繳固定支出 (Bills - 信用卡代繳)**：如水電費、電信網路、串流訂閱等（灌入信用卡帳單，在卡片扣款日一起扣）。
- **C. 信用卡實體消費與分期 (Cards & Installments)**：
  - 各分期的本期應付金額 (`monthlyAmount`)。
  - 各卡登記的本期帳單金額（包含一般刷卡消費與上述代繳）。

### 3. Manager 的核心設計構想（架構調整）
- **趨勢圖搬遷與重定義**：
  - 原「12 個月銀行餘額跨月走勢圖」遷移至「銀行餘額 (Banks) 分頁」，符合跨月長期存款檢視。
  - 總覽頁（Dashboard）改為**「該月的現金流變化趨勢圖」**：
    - 聚焦於「當前所選的單一月份」。
    - X 軸刻度以真實時間進度為錨點：`1號`、`10號`、`20號`、`月底`。
    - 若切換至「過去月份」，能精準重現該月份在 1號、10號、20號、月底的現金水位與流量消長。


### 4. 2026-11-04 關鍵討論：消除資訊重複與財務心智重塑 (收支餘裕 vs 入不敷出)
- **時序長條軸重複性問題**：
  - 總覽頁的 cashflowTimelineCard 與收支規則頁的 
ulesTimelineContainer 完全重複。
  - **定案評估**：總覽頁面應保持高階決策與視覺清爽，長條軸屬於「規則設定與檢視」，應收斂保留在「收支規則」分頁；總覽頁面改由「該月現金流變化趨勢圖 (1, 10, 20, 月底)」承擔時序變化。
- **真實財務心智模型：不能將信用卡與固定費用混為一談**：
  - 目前將信用卡與固定費用加總為單一「待扣負債」，使用者無法辨識是「常態性超支」還是「突發性大額消費」。
  - **三層流出拆解**：
    1. **第一層：剛性固定支出 (Hard Fixed Costs)** = 房租/房貸 + 車貸 + 各項進行中分期（扣款日前已知必扣金額）。
    2. **第二層：浮動固定生活費 (Utility / Variable Bills)** = 水電瓦斯、網路、手機通訊（金額浮動但每月必有）。
    3. **第三層：當月變動消費與突發大額 (Discretionary & Big Expenses)** = 扣除上述兩者後的真實消費（機票、聚餐等）。
  - **核心決策 KPI：本月現金流餘裕 (Monthly Cashflow Margin)**：
    	ext{每月淨現金流餘裕} = 	ext{常態收入} - 	ext{剛性固定支出} - 	ext{浮動固定生活費}
    此餘裕才代表「我有多少空間可以支持信用卡日常消費與資產投資成長」，一眼看出是否「入不敷出」。

### 5. 2026-11-04 右卡「現金流防禦與收支餘裕卡片」重構計畫
- **重構目的**：取代原本單純「待扣負債加總」，轉為「剛性固定支出 ➔ 浮動生活費 ➔ 本月現金流餘裕 (防入不敷出)」的決策卡片。
- **元素改造對照**：
  1. **大主數據 (Hero KPI)**：
     - 原：本月待扣總額 (卡費+固定費加總)
     - 新：**「本月淨現金流餘裕 (可自由支配/投資空間)」**（例如：NT$ +18,500 綠字，若透支則為紅字警示）
     - 輔助標示：常態收入 NT$ 58,000 - 剛性與生活固定負擔 NT$ 39,500
  2. **右上徽章 (Status Badge)**：
     - 原：自動扣繳檢核
     - 新：**「收支體質評估」**（例如：餘裕充裕 (32%)、剛性負擔過高 (75%) 或 ⚠️ 本月入不敷出）
  3. **下方三層結構拆解 (Sub Breakdown)**：
     - **① 剛性固定支出**：房租/車貸 + 各卡分期 (NT$ XX,XXX)
     - **② 浮動固定支出**：水電/網路/手機/公用事業 (NT$ X,XXX)
     - **③ 本期變動卡費/大額**：當月純刷卡與大筆支出 (NT$ XX,XXX，含機票等標註)

### 6. 2026-11-04 總覽頁功能重構規劃清單（即將派工候選清單）

#### 功能 A：總覽頁右卡重構為「本月收支餘裕與防入不敷出決策卡」
- **主數據**：改為 本月現金流餘裕 (常態收入 - 剛性固定 - 浮動生活費 - 當期卡費)，正數綠字、透支紅字警示。
- **右上徽章**：收支體質指標 (負擔率 % / 入不敷出警示)。
- **三層明細**：① 剛性固定負擔 (房租/車貸 + 各卡分期)、② 浮動生活帳單 (水電/通訊)、③ 當期變動消費 (純卡費 + 大額消費註記)。

#### 功能 B：總覽頁趨勢圖改為「該月份現金流變化走勢圖 (1, 10, 20, 月底)」
- **走勢圖職責分離**：
  - 原「12 個月跨月資產趨勢圖」遷移至「銀行餘額 (Banks) 分頁」。
  - 總覽頁圖表聚焦於「所選單月份」，X 軸固定為 1號、10號、20號、月底 四大關鍵節點，清晰看清當月水位的起伏消長（扣租、扣卡費、發薪入帳）。

#### 功能 C：總覽頁視覺瘦身與去重（移除長條時序軸）
- **移除項目**：移除總覽頁的 cashflowTimelineCard（1~31 號刻度軸），消除與「收支規則」分頁的重複冗餘，使首頁聚焦在高階決策。

#### 功能 D：三段式時間切換引擎 (ADR-016 落地：過去存量 / 當月防禦 / 未來整月流量)
- **過去月份 (前月)**：待扣自動歸零，呈現月底結算最終淨資產與餘額實數。
- **當前月份 (今天)**：以今天為游標，顯示當月時序日進度與即將到期防禦。
- **未來月份 (次月)**：呈現整月流量變化 (預估總流入 - 剛性與常態負擔 = 預估淨現金流) 與期末推估水位，不再落入無意義的單日切片。
