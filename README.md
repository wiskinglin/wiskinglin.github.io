## 觀察筆記專題策展備忘錄（Series Dossiers）

為了維持每週 1～2 篇的穩定產出並累積長期主題脈絡，全站觀察筆記在不更動三大主分類（科技與 AI、商業與市場、生活與設計）的前提下，以 `series` 欄位收斂為 4 條常駐專題線：

### 1. `ai-dev`｜AI實戰與開發（基底 14 篇）
* **描述**：看 AI 怎麼接手寫程式、做簡報、跑測試，以及本機工作流與算力應用的實戰紀錄。

### 2. `business-solo`｜商業與一人公司（基底 22 篇）
* **描述**：聊商業模式、產品定價、團隊管理，以及小團隊與一人公司如何打造護城河。

### 3. `tech-garage`｜科技玩物與車庫（基底 6 篇）
* **描述**：手機、筆電、電視、遊戲機到汽機車，寫每天摸得到、開出門的硬體與移動觀察。

### 4. `life-design`｜思考生活與設計（基底 7 篇）
* **描述**：整理閱讀筆記、投資防呆、日常習慣實驗，以及視覺排版與生活設計的心得。

### 發新文章備忘流程
1. 在 `reports/` 新增報告 HTML（依既有編輯室四段結構：核心脈絡 → 底層機制 → 對比表格 → 限制與結論）。
2. 在 `assets/js/klio-reports-data.js` 的 `KLIO_REPORTS` 陣列最前方加入該篇資料，並加上 `"series": "<專題ID>"`（跨專題單篇可額外加 `"relatedFiles": ["檔案1.html", "檔案2.html"]`）。
3. 首頁專題篩選、文章頂部專題膠囊、側欄推薦與文末閱讀路徑皆會由 `assets/js/klio-shell.js` 自動串接完成。
