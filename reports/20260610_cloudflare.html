D1 邊緣 SQL SQLite 全托管庫

SCALE TO ZERO

D1 基於 SQLite 構建，透過前端 Worker 代理 single-thread 實例以保證絕對事務一致性。其計費採用極具顛覆性的「按讀寫列計費」模型。

計費指標 免費方案 (每日) 付費方案 (每月)
資料列讀取 5,000,000 列 首 250 億列免費 ($0.001/M)
資料列寫入 100,000 列 首 5000 萬列免費 ($1.00/M)
總儲存空間 最大 5 GB 5 GB 免費 (超額 $0.75/GB)
全域讀取副本 (Global Read Replication)

D1 原生內置主從副本同步。為防止副本延遲，應使用 Sessions API 建立書籤（withSession(bookmark)），確保順序一致性與單調讀取。

單庫容量天花板: 10 GB 單橫列容量上限: 2 MB

Workers KV 全球讀取優化庫

EVENTUAL CONSISTENCY

KV 犧牲了寫入傳播的強一致性，以背景非同步廣播換取 Sub-10ms 全網讀取延遲。然而其寫入計費成本為讀取成本的 10 倍。

計費指標 免費方案 (每日) 付費方案 (每月)
讀取操作 (Reads) 100,000 次 10,000,000 次 ($0.50/M)
寫入操作 (Writes) 1,000 次 1,000,000 次 ($5.00/M)
命名空間限制 1,000 個 / 帳戶 1,000 個 / 帳戶

最佳實踐場景

A/B測試旗標、語系翻譯字典、微服務靜態路由配置。

絕對反模式

金融餘額儲存、高頻即時庫存。否則易出現嚴重的帳單與一致性撕裂。

寫入傳播期: 最長 60 秒 單個 Key 最大長度: 512 Bytes

1. Workers CPU 限制與 Wall-clock time ALERT 1102

免費方案單次請求享 10ms 限制；付費版 CPU 上限可放寬至 5 分鐘。 重要觀念：CPU 時間僅計算 V8 引擎實際運算週期；所有的 await fetch()、D1 資料庫回源或 R2 讀寫產生的等待期，均不計入 CPU 消耗。

* 超過 CPU 限制將擲回 1102 Worker exceeded resource limits 錯誤。

2. Queues 佇列與 Workflows 狀態機 FREE tier

Queues 已正式下放至免費版（最大1萬個佇列，每日1萬次操作）。Payload 以 64 KB 作為計費區塊單位。 Workflows 全面整合於現有 Workers 計費架構（僅需付 $0.20/GB-月 狀態儲存費）。

3. Workers AI 神經元經濟學

DLP / Guardrails

每日提供所有用戶 10,000 個免費神經元（Neurons）。耗盡後付費層按 $0.011/K神經元 計費，免費層直接阻斷並回傳 3036 異常。AI Gateway 整合 DLP 防止機密外洩。

BLUEPRINT

Cloudflare 最佳化架構合成指南 (Synthesis)

① 責任與實體完全分離 (Object-per-entity)

嚴禁將任何大型 Blob、圖片或上傳文檔直接寫入 D1 或 KV。這些檔案一律歸入 R2 (免除 Egress 費)；而 D1 與 KV 僅記錄 URL 與 Meta 中繼資料。

② 動靜分離與快取分層 (Dynamic-Static Split)

前端靜態資源丟 Pages 託管 (請求完全免費)；極少變更的路由、多語系翻譯塞 KV (享亞毫秒極致快取)；複雜關聯資料歸 D1 持久化，並開啟全域唯讀副本。

③ 強一致性混合存儲 (The Hybrid DO-D1 Pattern)

面對即時遊戲、協作編輯、電商秒殺等並發更新，應使用單執行緒 Durable Objects 作為「即時真相來源」，再用 DO Alarms 定期背景同步穩態資料至 D1 作為「歷史分析來源」。

④ 免費額度網異步解耦 (Decouple with Queues)

巧妙劃分微服務。利用 Queues 與 Workflows 進行異步非同步解耦與突發流量削峰，新創團隊甚至能實現 100% 零基礎設施成本的全球架構。
