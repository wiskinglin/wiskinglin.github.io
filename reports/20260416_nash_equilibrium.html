賽局理論推演：純策略與混合策略奈許均衡求解

拆解 3×3 非合作賽局的雙邊報酬矩陣，先透過最佳回應找出唯一的純策略均衡。接著剔除嚴格劣勢策略降維，再利用無異條件算出兩組混合策略奈許均衡。

一、核心脈絡與關鍵問題：從 3×3 報酬矩陣尋找穩定均衡

雙方沒有具約束力的協議，必須同時出招並各自承擔結果。面對雙邊各有三個選項的 3×3 賽局，單憑直覺只會看見局部最優，忽略對手同步換招後的連鎖反應。甲（列玩家）與乙（行玩家）都想把自身報酬放到最大。接下來的推演要找出所有奈許均衡（Nash Equilibrium），也就是雙方都不想單方面換招的穩定組合。

甲有 U、C、D 三種行動，乙有 L、M、R 三種行動，雙邊報酬整理在下表。括號裡第一個數字代表甲的報酬，第二個數字代表乙的報酬。

甲 \ 乙 L M R
U (1, 3) (4, 2) (3, 4)
C (5, 1) (1, 2) (2, -1)
D (3, 5) (2, 3) (2, 7)

二、底層機制與因果拆解：最佳回應、劣勢剔除與無異條件

1. 最佳回應與純策略均衡

尋找純策略均衡的第一步，是鎖定對手的單一行動，找出己方的最佳回應（Best Response）。當雙方在同一個組合裡互為最佳回應，這個點就站穩了。此時任何一方單獨換招，報酬只會變差或持平。

  • 甲的最佳回應（比較括號內第一個數值）：
    • 若乙選 L，甲選 C 報酬最高（5 > 3, 1）。
    • 若乙選 M，甲選 U 報酬最高（4 > 2, 1）。
    • 若乙選 R，甲選 U 報酬最高（3 > 2, 2）。
  • 乙的最佳回應（比較括號內第二個數值）：
    • 若甲選 U，乙選 R 報酬最高（4 > 3, 2）。
    • 若甲選 C，乙選 M 報酬最高（2 > 1, -1）。
    • 若甲選 D，乙選 R 報酬最高（7 > 5, 3）。

交叉比對兩份名單，只有甲選 U、乙選 R 時，甲的報酬 3 與乙的報酬 4 同時落在最高點。這場賽局唯一的純策略奈許均衡就是 (U, R)。

2. 剔除嚴格劣勢策略降維

算混合策略之前，先檢查矩陣裡有沒有嚴格劣勢策略（Strictly Dominated Strategy）。只要某個選項在對手所有出招下的報酬，都嚴格低於另一個純策略或混合策略，理性玩家就不會在它身上放任何機率。

觀察甲的策略 D，對應報酬是 (3, 2, 2)。若甲改採混合策略，以機率 p = 0.4 選 U、1 - p = 0.6 選 C，面對乙的三種行動，期望報酬分別是：

  • 對應乙選 L：0.4 × 1 + 0.6 × 5 = 3.4 > 3
  • 對應乙選 M：0.4 × 4 + 0.6 × 1 = 2.2 > 2
  • 對應乙選 R：0.4 × 3 + 0.6 × 2 = 2.4 > 2

混合策略 (0.4U + 0.6C) 在乙的三種出招下都贏過 D，代表 D 是嚴格劣勢策略。把 D 剔除後，原本的 3×3 矩陣就縮成甲只剩 U、C 兩列的 2×3 賽局，後續少算一個維度。

3. 無異條件與混合策略求解

在混合策略均衡裡，玩家要調整自己的機率分佈，讓對手在幾個選中的純策略之間感到無異（Indifferent）。對手拿到的期望報酬一樣，才不會把機率全押到單一選項。設甲以機率 p 選 U、1 - p 選 C，乙的期望報酬 E(L)、E(M)、E(R) 分別為：

  • E(L) = 3p + 1(1 - p) = 2p + 1
  • E(M) = 2p + 2(1 - p) = 2
  • E(R) = 4p - 1(1 - p) = 5p - 1

接著分三種配對，檢驗乙能不能混合其中兩項策略。如果沒被選中的第三招報酬更高，該配對就不成立：

  • 情況一（乙混合 L 與 M，不選 R）：令 E(L) = E(M)，解得 2p + 1 = 2，即 p = 1/2。此時 E(R) = 5(1/2) - 1 = 1.5 < 2，乙不會改選 R。接著設乙以機率 q 選 L、1 - q 選 M。為了讓甲對 U 與 C 無異，列出 1q + 4(1 - q) = 5q + 1(1 - q)，解得 4 - 3q = 4q + 1，也就是 q = 3/7。第一組混合策略均衡為甲 (1/2, 1/2, 0)、乙 (3/7, 4/7, 0)。
  • 情況二（乙混合 L 與 R，不選 M）：令 E(L) = E(R)，解得 2p + 1 = 5p - 1，即 p = 2/3。此時 E(M) = 2 < E(L) = 7/3，乙不會改選 M。接著設乙以機率 q 選 L、1 - q 選 R。為了讓甲對 U 與 C 無異，列出 1q + 3(1 - q) = 5q + 2(1 - q)，解得 3 - 2q = 2 + 3q，也就是 q = 1/5。第二組混合策略均衡為甲 (2/3, 1/3, 0)、乙 (1/5, 0, 4/5)。
  • 情況三（乙混合 M 與 R，不選 L）：若令 E(M) = E(R)，會解得 p = 0.6。但此時 E(L) = 2(0.6) + 1 = 2.2 > 2，乙會直接改選純策略 L，不會混合 M 與 R，這組假設不成立。

四、適用邊界、限制與結論行動

這套求解流程假設雙方同時出招、報酬公開，且決策者風險中立、只追求期望效用最大。它也預設賽局只玩單次，沒有長期的重複懲罰機制。一旦市場出現資訊不對稱、分先後出招，或存在長期合作誘因，靜態奈許均衡的預測力就會下降。這時得改用貝氏賽局或子賽局完美均衡重新建模。

比較三組均衡的報酬，純策略均衡 (U, R) 給甲 3、給乙 4，同時高於混合均衡一的 (19/7, 2)（約 2.71 與 2）與混合均衡二的 (13/5, 7/3)（約 2.6 與 2.33）。在柏拉圖效率上，(U, R) 對雙方都更有利。面對多均衡共存的賽局，第一步是剔除嚴格劣勢選項來縮小範圍。接著透過明確的訊號傳遞，引導對手收斂到高報酬的純策略均衡，才能避開互相猜忌的低報酬混合陷阱。
