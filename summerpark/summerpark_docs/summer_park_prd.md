《Summer Park》專案總企劃書與架構分析
一、 專案概述
遊戲名稱： Summer Park（夏日公園）
遊戲類型： PWA 跨平台網頁養成遊戲 (放置/收集/輕度 RPG)
核心賣點： 以柯基犬的「短腿」、「大屁股」為視覺焦點，主打夏日陽光、輕鬆療癒的日常陪伴。
目標平台： Windows PC、iPhone (Safari)、Android (Chrome) —— 透過 PWA 技術實現免下載、免安裝商店、直接新增至主畫面的原生級體驗。
二、 遊戲設計與核心循環 (玩家吸引力分析)
本遊戲的核心閉環為「照顧 ➔ 成長 ➔ 探索 ➔ 社交」，每一個環節都經過精心設計，利用不同的心理學回饋機制來緊緊抓住玩家的心：
基礎照顧（情感羈絆與心流建立）：
機制： 餵食、洗澡、互動，維持屬性並產出基礎貨幣（狗骨頭）。
吸引力分析： 利用「電子雞效應 (Tamagotchi Effect)」，透過低門檻的點擊互動獲得柯基即時的可愛反應（如：開心的笑容、瘋狂搖動的屁股），建立玩家與虛擬寵物間的情感羈絆。短暫且高頻的日常任務能讓玩家每天毫無壓力地打開遊戲，形成習慣。
屬性培育（成長反饋與目標感）：
機制： 透過輕量級節奏或策略訓練，提升柯基的「速度、魅力、智商」。
吸引力分析： 提供清晰的數值成長目標。當屬性提升時，解鎖柯基新的動態表現或特殊叫聲，給予玩家實質的「投入回報感 (Return on Investment)」，讓玩家確信自己的時間投入是有價值的。
夏日大冒險（隨機性與期待感）：
機制： 派遣柯基前往夏日專屬地圖（陽光綠地、夏日海灘、森林營地）進行隨機事件探索，帶回稀有道具或解鎖圖鑑。
吸引力分析： 這是遊戲最核心的「斯金納箱 (Skinner Box)」機制。散步時間結束前充滿了「不知道會帶回什麼」的期待感。隨機掉落的稀有道具或意外事件會觸發玩家腦內的多巴胺分泌，這種「變動比率增強」是讓玩家持續回訪確認遊戲進度的最強動力。
外觀與圖鑑（收集癖與社交貨幣）：
機制： 收集各種搞笑可愛的「屁屁姿勢圖鑑」，以及裝備各種飾品（草帽、太陽眼鏡、泳圈）。
吸引力分析： 滿足玩家的「收集癖」與「完整性強迫症」。而稀有的裝扮或極度搞笑的屁屁姿勢，則會轉化為玩家在社群上的「社交貨幣」，驅使他們截圖分享，獲得朋友的關注與按讚。
三、 美術與素材製作規劃 (Art & Assets Strategy)
(本遊戲成功的核心關鍵)
《Summer Park》的美術策略核心在於「高識別度的萌感」與「極致的動態反饋」。因為網頁遊戲無法提供複雜的 3D 操作，我們必須透過高質量的 2D 視覺表現與細膩的 Spine 動畫，將柯基的「短腿」和「大屁股」特色極大化，讓每一次點擊都能產生強烈的情感回饋。以下為詳細的素材規劃與設計規範：
1. 視覺風格與色彩計畫 (Visual Identity & Color Palette)
核心風格： 採用日系厚塗結合 2D 向量風格。線條圓潤無銳角，陰影處理柔和，強調物件的「Q 彈感」與「蓬鬆感」。
色系設定： 以溫暖、明亮的夏日色調為主。
主色調： 陽光橙黃 (#FFD166)、柯基焦糖色 (#EAA850)。
輔助色： 鮮草綠 (#06D6A0) 營造生機、天空藍 (#118AB2) 代表清爽、肉墊粉 (#EF476F) 用於 UI 點綴與重點提示。
禁忌色： 避免使用大面積的高飽和螢光色、暗沉的灰黑色，以維持遊戲整體的療癒與無壓感。
2. 角色動態與表現 (Character Animation - Spine 2D)
柯基是遊戲的靈魂，其動畫必須極度細緻，將物理限制（短腿）轉化為喜劇效果（滑稽、努力的萌感）。所有動畫需導出為 WebGL 優化版本以確保網頁端流暢度。
基礎待機 (Idle)： 呼吸時腹部的起伏、耳朵偶爾抖動、尾巴（或小肉塊）輕微搖擺。
移動循環 (Walk/Run)：
走路： 經典的「小碎步」，重點強調屁股左右劇烈搖晃的節奏感（Jiggle Physics）。
跑步： 腿太短導致看起來像在地上滑行，身體前傾，耳朵往後貼，舌頭伸長。
互動反饋 (Interaction)：
撫摸： 舒服地瞇眼、翻肚皮露出粉紅肉墊、發出呼嚕聲。
戳弄/驚嚇： 嚇一跳往後跳（但跳不高），發出短促的汪汪聲，生氣時會用短腿快速跺腳。
進食： 臉頰塞滿食物鼓起，發出滿意的咀嚼聲，吃飽後會打嗝並用短腿摸肚子。
特殊「屁屁」展現 (Butt-centric Animations)：
趴下： 標準的「吐司麵包」趴姿，後腿向後伸直（Sploot），重點刻畫屁股的圓潤曲線。
卡住： （散步事件中）頭鑽進草叢或洞裡，只露出大屁股在外扭動求救的動畫。
3. 場景設計 (Environment Design)
場景需配合 RWD 雙欄佈局（手機版展示中央區塊，PC 版展示全貌），並帶有微動態（如光影變化、樹葉飄動）以增加生機。
主基地（溫馨客廳/陽台）：
木質地板、大片落地窗透進陽光。
可放置各種狗狗家具（軟骨頭坐墊、水盆、散落的玩具）。
光影需隨現實時間變化（早晨明亮、傍晚夕陽、夜晚昏黃小夜燈）。
夏日專屬散步地圖 (Exploration Maps)：
陽光綠地 (Sunny Park)： 翠綠的草皮、灑落光斑的大樹、遠處有推車小販。物件如長椅、消防栓可供柯基互動。
夏日海灘 (Summer Beach)： 金黃色沙灘、拍打的白浪、沙堡與遮陽傘。海鷗飛過的陰影會掠過畫面。
森林營地 (Forest Camp)： 滿布小花徑的步道、營火堆、小帳篷。螢火蟲或蝴蝶會在場景中飛舞。
4. 裝備與扭蛋盲盒素材 (Gacha & Customization Assets)
紙娃娃系統是核心營收來源，裝扮設計必須極具創意、甚至帶有迷因屬性。
頭部裝飾： 遮陽草帽、飛行員墨鏡、向日葵頭套、西瓜皮安全帽。
身體裝飾（服裝）： 夏威夷花襯衫、蜜蜂裝（附帶小翅膀動態）、熱狗堡套裝、黃色小雨衣。
背部/配件： 小書包、充氣小鴨泳圈、綁在背上的竹蜻蜓、咬在嘴裡的法式麵包。
扭蛋演出動畫：
放棄傳統的「開箱子」，改為：一隻柯基奮力挖土，挖出普通骨頭（N）、精緻罐頭（SR），或挖出一個巨大發光寶箱（SSR），並配合專屬的華麗光效與歡呼音效。
5. UI/UX 與音效 (UI/UX & Audio Assets)
使用者介面 (UI)：
圖示設計：將按鈕設計成狗掌印、骨頭、飛盤形狀。
選單展開：採用類似「拉開抽屜」或「翻閱日記本」的動畫過渡，避免生硬的畫面切換。
聽覺體驗 (Audio)： 必須進行深度壓縮（WebM/AAC）以適應 PWA 網頁端。
BGM： 3 首不同情境的背景音樂。主畫面為烏克麗麗輕快曲風；海灘地圖加入海浪與海鷗的環境音；森林地圖加入蟲鳴與風吹樹葉聲。
音效 (SFX)： 收錄真實柯基犬的叫聲（開心、撒嬌、生氣），踩在不同材質（木板、沙子、草地）上的腳步聲，以及 UI 點擊時清脆的「啵」聲或木琴敲擊聲。
四、 技術與流量架構分析 (Cloudflare + PWA)
本專案的技術核心在於「極致的輕量化與低成本」，完美規避了傳統 App 開發的雙平台審核與高昂的伺服器維護費。
前端渲染： 採用 RWD 雙欄動態佈局（手機直屏適配、PC 寬屏擴展），素材全面採用 WebGL、WebP、WebM 以降低頻寬消耗。
PWA 離線與推播： 運用 Service Worker 實現離線快取，確保網路不穩時仍能遊玩；結合 Web Push 提供跨平台的「柯基回家」等事件推播。
「零伺服器」節流架構：
本地計算： 遊戲中的體力倒數、日常照顧等高頻操作，皆在玩家裝置前端 (LocalStorage/IndexedDB) 處理。
關鍵同步： 只有在登入、結算獎勵、付費等關鍵節點，才透過 Cloudflare Workers (API) 與 D1 (資料庫) 進行資料驗證與寫入。
五、 商業模式與 80% 毛利 (GP) 策略
藉由技術架構的優勢，本專案能夠實現突破業界常規的 80% 毛利率。我們捨棄月費/訂閱制，採用更靈活的儲值與抽獎機制：
省去平台抽成 (節省 ~25%)： 繞過 App Store / Google Play 的 30% 抽成，直接透過網頁端串接 Stripe / LINE Pay 等第三方金流，手續費僅需 3% - 5%。
極致壓縮開發端伺服器成本 (節省 ~10%)：
DAU < 500： 透過「節流架構」將每日 API 請求控制在 Cloudflare Workers 免費版的 10 萬次內，實現前期開發方 $0 伺服器成本。
DAU  500： 開發方伺服器自動升級至 Cloudflare 付費版（開發商每月僅需支付 $5 基礎設施費用起），享有千萬次請求額度，此時遊戲營收已遠遠超過此微小硬體成本。
高利潤變現設計（無月費制）：
主題盲盒扭蛋 (Gacha)： 核心付費點。推出如「夏日祭典」、「海洋派對」等主題扭蛋機，玩家消耗儲值幣抽取稀有（SSR）柯基外觀裝扮或特殊散步場景。零邊際成本創造極高利潤。
儲值兌換 (Top-up)： 玩家可直接儲值購買「黃金狗骨頭（付費代幣）」，用於商城直接購買特定心儀的道具、特殊高級罐頭，或購買加速券來立即完成散步探索。
六、 後台管理與營運規劃
採用 React/Vue + Tailwind CSS 打造輕量 Web 後台，並受 Cloudflare Access (Zero Trust) 嚴格保護：
數據即時看板： 監控 DAU、ARPU，特別是 Cloudflare API 請求量與 D1 讀寫量（成本預警）。
玩家與客服系統： 玩家數據查詢、違規封鎖、針對個別玩家發放補償。
行銷活動控制與全服贈禮（新増）：
發放系統： 營運人員可透過後台介面，無須更新程式碼，直接設定向全服或指定條件玩家（如：連續登入3天）派發虛寶、時裝或代幣獎勵。
活動排程： 彈性設定「節日加倍活動」、「限時登入送盲盒」等行銷事件的開啟與結束時間。
動態數值調整 (Config)： 可熱更新的扭蛋機率設定、商品定價與散步掉落率。
七、 社群行銷與裂變策略
利用網頁遊戲「點開即玩」的特性，最大化社群傳播力：
預熱期： 推出「測出你是哪種靈魂的柯基」心理測驗 H5 網頁，結合柯基迷因，導流至 PWA 預約安裝。
上線期 (內建裂變)： 開發遊戲內「一鍵生成明信片」功能，讓玩家將柯基的可愛瞬間（附帶專屬遊戲 QR Code）分享至 Threads / IG 限動。
社群活動： 舉辦全服共同目標（如累積散步里程），增加社群凝聚力與留存率。
